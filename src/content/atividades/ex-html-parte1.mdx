## Exercícios

<ExCard num={1} title="Estrutura Básica e Elementos de Texto">

**Instruções:**
1. Feche o elemento `<h1>` com a tag de fechamento correta
2. Adicione um `<p>` com o texto `My first paragraph.`
3. Dentro do parágrafo, adicione um `<br>` após a palavra `first`
4. Feche o `<body>`

```html
<!DOCTYPE html>
<html>
<body>
  <h1>My First Heading</h1>
  <p>My first<br> paragraph.</p>
</body>
</html>
```

> `<br>` é void element — sem tag de fechamento. O `</body>` vem depois de todo o conteúdo visível.

</ExCard>

<ExCard num={2} title="Imagem com Atributos">

**Instruções:**
1. Adicione `<img>` após o parágrafo
2. `src` = `img_girl.jpg`, `alt` = `Girl with a jacket`
3. `width` = `250`, `height` = `300`

```html
<!DOCTYPE html>
<html>
<body>
  <h1>My Gallery</h1>
  <p>Here is a photo:</p>
  <img src="img_girl.jpg" alt="Girl with a jacket" width="250" height="300">
</body>
</html>
```

</ExCard>

<ExCard num={3} title="Hierarquia de Headings">

**Instruções:** Use `<h1>` para `My Website`, `<h2>` para `About Me` e `My Hobbies`, `<h3>` para `Photography`.

```html
<!DOCTYPE html>
<html>
<body>
  <h1>My Website</h1>
  <h2>About Me</h2>
  <p>I love building web pages.</p>
  <h2>My Hobbies</h2>
  <h3>Photography</h3>
  <p>I enjoy taking photos of nature.</p>
</body>
</html>
```

</ExCard>

<ExCard num={4} title="Parágrafo, br, hr e pre">

```html
<!DOCTYPE html>
<html>
<body>
  <h1>A Short Poem</h1>
  <p>Twinkle twinkle little star,<br>
  How I wonder what you are.</p>
  <hr>
  <pre>
Up above the world so high,
Like a diamond in the sky.
  </pre>
</body>
</html>
```

> `<pre>` preserva toda a formatação. `<br>` força uma quebra pontual dentro de um parágrafo comum.

</ExCard>

<ExCard num={5} title="Estilos Inline">

```html
<!DOCTYPE html>
<html>
<body style="background-color:powderblue;">
  <h1 style="color:blue;font-family:verdana;">Welcome</h1>
  <p style="text-align:center;font-size:20px;">Styled paragraph.</p>
</body>
</html>
```

> Em projetos reais, estilos vivem em arquivos `.css` separados. O `style=` inline é só pra ver o resultado imediato.

</ExCard>

<ExCard num={6} title="Formatação Semântica">

**Instruções:** `important` → `<strong>`, `carefully` → `<em>`, `milk` → `<mark>`, o `2` em H2O → `<sub>`, `blue` → `<del>`

```html
<!DOCTYPE html>
<html>
<body>
  <p>This is an <strong>important</strong> message.</p>
  <p>Please read <em>carefully</em>.</p>
  <p>Do not forget to buy <mark>milk</mark> today.</p>
  <p>The formula for water is: H<sub>2</sub>O</p>
  <p>My favorite color is <del>blue</del> red.</p>
</body>
</html>
```

</ExCard>

</ExCard>

<ExCard num={8} title="Comentários">

**Instruções:** Adicione um comentário `This is the navigation` antes do primeiro parágrafo. Comente o segundo parágrafo.

```html
<!DOCTYPE html>
<html>
<body>
  <h1>My Website</h1>
  <!-- This is the navigation -->
  <p>Home | About | Contact</p>
  <!-- <p>This paragraph should be hidden.</p> -->
</body>
</html>
```

</ExCard>

## Checklist antes de entregar

- `<!DOCTYPE html>` na primeira linha
- `lang="pt-BR"` no `<html>`
- `<meta charset="UTF-8">` como primeira tag do `<head>`
- `<meta name="viewport">` presente
- `<title>` preenchido
- Todas as tags abertas estão fechadas
- Imagens com `alt` descritivo
- Nenhum erro no [W3C Validator](https://validator.w3.org)
