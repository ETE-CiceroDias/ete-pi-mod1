## O desafio

Com tudo que você aprendeu nas duas aulas de HTML, construa uma página do zero — sem CSS, só estrutura. O tema é completamente livre: sobre você, um artista, um jogo, uma série, uma causa, uma cidade, qualquer coisa que você genuinamente curta.

O que importa é que a página tenha **identidade real** — não seja uma cópia do exemplo de sala.

<Callout type="tip" title="Escolha algo que você realmente gosta">
  Páginas sobre temas que o autor domina e curte ficam melhores. Se você é fã de um artista, escreva sobre a discografia com propriedade. Se curte um jogo, explique a lore. Autenticidade aparece no HTML.
</Callout>

## Requisitos obrigatórios

Todos os itens abaixo precisam estar presentes e funcionando:

- Estrutura completa: `<!DOCTYPE html>`, `<html lang="pt-BR">`, `<head>` com charset + viewport + title, `<body>`
- Estrutura semântica: `<header>`, `<main>`, `<footer>` — pelo menos dois `<section>` com `id`
- Um `<nav>` com links âncora funcionando (`href="#id"`)
- Hierarquia de headings correta — um único `<h1>`, `<h2>` e `<h3>` conforme necessário
- Pelo menos um uso de `<strong>`, `<em>`, `<mark>` ou `<del>`
- Uma lista (`<ul>` ou `<ol>`) com mínimo 4 itens
- Uma imagem com `src`, `alt` descritivo e `width`
- Um link externo com `target="_blank"` e `rel="noopener noreferrer"`
- Pelo menos uma `<abbr>` com `title`
- Pelo menos dois comentários explicando seções do código
- Código validado no W3C sem erros

## Critérios de avaliação

| Critério | Peso | O que será observado |
|---|---|---|
| **Validade** | 25% | Zero erros no W3C Validator |
| **Semântica** | 30% | header, nav, main, section, footer usados corretamente |
| **Acessibilidade** | 20% | alt descritivos, label conectado ao input, lang correto |
| **Criatividade** | 25% | A página tem identidade — não é cópia do exemplo |

## Como entregar

1. Crie uma pasta com seu nome: `nome-sobrenome/`
2. Coloque o `index.html` dentro
3. Suba no GitHub dentro do repositório da turma
4. Cole o link do repositório no Google Classroom até a data de entrega

<Callout type="warn" title="Sem CSS — ainda">
  Esta entrega é só HTML. Não use `style=` para estilizar o layout geral — inline style só é permitido nos exercícios guiados, onde serve para ver o resultado sem criar um segundo arquivo. A beleza vem na próxima aula.
</Callout>
