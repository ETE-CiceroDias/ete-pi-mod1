## 1. `<div>` e `<span>` — Os Contêineres

`<div>` e `<span>` são elementos **sem significado semântico** — eles não dizem o que o conteúdo é, apenas o agrupam para fins de estilo ou manipulação com JavaScript.

| Tag | Tipo | Uso |
|---|---|---|
| `<div>` | Bloco | Agrupa seções inteiras, colunas, cards |
| `<span>` | Inline | Destaca uma palavra ou trecho dentro de um parágrafo |

```html
<!-- div: bloco — ocupa a linha toda -->
<div class="card">
  <h2>Título do Card</h2>
  <p>Conteúdo do card aqui.</p>
</div>

<!-- span: inline — fica dentro do texto -->
<p>O preço é <span class="preco">R$ 49,90</span> à vista.</p>
```

<Callout type="warn" title="div e span não são semânticos">
  Prefira sempre tags semânticas quando o conteúdo tiver significado: `<article>`, `<section>`, `<nav>`, `<header>`, `<footer>`. Use `<div>` e `<span>` apenas quando nenhuma tag semântica se encaixa — geralmente para fins de layout e estilo.
</Callout>

## 2. Formatação de Texto — Continuação

Na aula passada vimos `<strong>` e `<em>`. Completando o conjunto:

| Tag | Significado Semântico | Visual padrão |
|---|---|---|
| `<mark>` | Texto destacado / relevante | Fundo amarelo |
| `<del>` | Texto removido / desatualizado | Tachado |
| `<ins>` | Texto inserido / novo | Sublinhado |
| `<sub>` | Subscrito | Abaixo da linha |
| `<sup>` | Sobrescrito | Acima da linha |
| `<small>` | Texto de menor importância | Menor |
| `<code>` | Código inline | Monoespaçado |

```html
<p>O produto custava <del>R$ 120,00</del> <ins>R$ 89,90</ins>.</p>
<p>A fórmula da água é H<sub>2</sub>O.</p>
<p>2<sup>10</sup> = 1024.</p>
<p>Use a tag <code>&lt;p&gt;</code> para parágrafos.</p>
<p><mark>Atenção:</mark> esta promoção termina hoje.</p>
```

## 3. Links — Completo

Na aula anterior vimos o básico. Agora o quadro completo:

```html
<!-- Link externo — abre em nova aba -->
<a href="https://developer.mozilla.org" target="_blank" rel="noopener noreferrer">
  MDN Web Docs
</a>

<!-- Link interno — vai para outra página do mesmo site -->
<a href="sobre.html">Sobre mim</a>

<!-- Âncora — vai para um elemento na mesma página -->
<a href="#contato">Ir para Contato</a>

<!-- Link de email — abre o app de email -->
<a href="mailto:nome@email.com">Enviar email</a>

<!-- Link de telefone — funciona em mobile -->
<a href="tel:+5581999999999">Ligar agora</a>
```

| Atributo | Valores | O que faz |
|---|---|---|
| `href` | URL, `#id`, `mailto:`, `tel:` | Destino do link |
| `target` | `_blank`, `_self` | Onde abrir — nova aba ou mesma |
| `rel` | `noopener noreferrer` | Segurança para links externos |
| `download` | (sem valor ou nome) | Força download do arquivo linkado |

<Callout type="tip" title="Por que rel='noopener noreferrer'?">
  Quando você abre um link com `target="_blank"`, a nova página pode acessar a sua via `window.opener`. O atributo `rel="noopener noreferrer"` bloqueia isso — é uma prática de segurança obrigatória em links externos.
</Callout>

## 4. Citações e Abreviações

```html
<!-- Citação em bloco — para citações longas -->
<blockquote cite="https://www.w3.org">
  <p>A Web é para todos.</p>
  <footer>— Tim Berners-Lee</footer>
</blockquote>

<!-- Citação inline — dentro de um parágrafo -->
<p>Como disse Berners-Lee: <q>A Web é para todos.</q></p>

<!-- Abreviação — mostra significado completo como tooltip -->
<p>Aprenda <abbr title="HyperText Markup Language">HTML</abbr> hoje.</p>

<!-- Definição — primeira ocorrência de um termo -->
<p><dfn>Semântica</dfn> é o estudo do significado.</p>
```

| Tag | Uso |
|---|---|
| `<blockquote>` | Citação longa, em bloco separado |
| `<q>` | Citação curta, inline (adiciona aspas automaticamente) |
| `<cite>` | Título de uma obra (livro, filme, música) |
| `<abbr>` | Abreviação com explicação via tooltip |
| `<dfn>` | Definição de um termo |

## 6. Inputs — Primeiros Passos

Inputs são os elementos que permitem ao usuário inserir dados. Por enquanto, só a estrutura — sem `<form>` e sem funcionamento real.

```html
<!-- Texto simples -->
<input type="text" placeholder="Seu nome" name="nome">

<!-- Email -->
<input type="email" placeholder="seu@email.com" name="email">

<!-- Senha (oculta o texto) -->
<input type="password" placeholder="Senha" name="senha">

<!-- Número -->
<input type="number" min="0" max="100" name="idade">

<!-- Checkbox -->
<input type="checkbox" id="aceito" name="aceito">
<label for="aceito">Aceito os termos</label>

<!-- Radio button -->
<input type="radio" id="sim" name="resposta" value="sim">
<label for="sim">Sim</label>
<input type="radio" id="nao" name="resposta" value="nao">
<label for="nao">Não</label>

<!-- Botão de envio -->
<button type="submit">Enviar</button>
```

<Callout type="info" title="label e for — acessibilidade">
  O atributo `for` no `<label>` deve ter o mesmo valor do `id` do input. Isso conecta os dois: clicar no texto do label já ativa o campo. É essencial para acessibilidade.
</Callout>

| Atributo | O que faz |
|---|---|
| `type` | Define o tipo do campo (text, email, password, number...) |
| `placeholder` | Texto de exemplo que some ao digitar |
| `name` | Identificador do campo ao enviar o formulário |
| `id` | Identificador único — necessário para conectar ao `<label>` |
| `required` | Torna o campo obrigatório |
| `disabled` | Desativa o campo |

## 7. Elementos Semânticos de Estrutura

Antes do CSS, vale conhecer as tags que organizam a página de forma semântica:

| Tag | Uso |
|---|---|
| `<header>` | Cabeçalho da página ou seção |
| `<nav>` | Menu de navegação |
| `<main>` | Conteúdo principal (único por página) |
| `<section>` | Seção temática do conteúdo |
| `<article>` | Conteúdo independente (post, notícia) |
| `<aside>` | Conteúdo relacionado mas lateral (sidebar) |
| `<footer>` | Rodapé da página ou seção |

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha Página</title>
</head>
<body>
  <header>
    <h1>Nome da Página</h1>
    <nav>
      <a href="#sobre">Sobre</a>
      <a href="#contato">Contato</a>
    </nav>
  </header>

  <main>
    <section id="sobre">
      <h2>Sobre</h2>
      <p>Conteúdo sobre mim.</p>
    </section>
  </main>

  <footer>
    <p>© 2026 · Meu Site</p>
  </footer>
</body>
</html>
```

## Desafio Final — Página sobre o que você ama

Com tudo que aprendemos nas duas aulas de HTML, construa sua página pessoal completa. O tema é livre: sobre você, sobre um artista, um jogo, uma série, uma causa — o que você genuinamente quiser.

### 📋 Requisitos

- Estrutura semântica completa: `<header>`, `<main>`, `<footer>`, `<nav>`
- Pelo menos duas `<section>` com `id` para navegação por âncoras
- Um `<nav>` com links âncora funcionando
- Uso de `<strong>`, `<em>`, `<mark>` ou `<del>` no conteúdo
- Uma lista (`<ul>` ou `<ol>`) com mínimo 4 itens
- Uma imagem com `src`, `alt` e `width`
- Um link externo com `target="_blank"` e `rel="noopener noreferrer"`
- Um link de email ou telefone
- Pelo menos uma `<abbr>` com `title`
- Código validado no W3C sem erros

### 🏆 Critérios de Avaliação

| Critério | O que será observado |
|---|---|
| **Validade** | Sem erros no W3C Validator |
| **Semântica** | Uso correto de header, nav, main, section, footer |
| **Acessibilidade** | alt descritivo, label conectado ao input |
| **Criatividade** | A página tem identidade — não é cópia do exemplo |
