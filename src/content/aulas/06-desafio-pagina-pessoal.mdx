## Sobre este Desafio

Chegou a hora de juntar tudo. Ao invés de exercícios guiados, você vai construir uma página **do zero**, com tema livre, usando todos os elementos das aulas anteriores.

O tema é você escolher: pode ser sobre um artista, um jogo, uma série, um esporte, uma causa — **qualquer coisa que você genuinamente curta**. O que importa é que a página fale de verdade, não seja uma cópia do exemplo.

---

## Requisitos

- Estrutura HTML completa: `<!DOCTYPE html>`, `<html lang="pt-BR">`, `<head>` com charset + viewport + title, `<body>`
- Um `<h1>` com o título da página
- Hierarquia de headings coerente: `<h2>` para seções, `<h3>` para subseções
- No mínimo 2 parágrafos com uso de `<strong>` ou `<em>`
- No mínimo 2 imagens com `src`, `alt` descritivo e `width`
- Uma lista não-ordenada `<ul>` com no mínimo 3 itens
- Uma lista ordenada `<ol>` com no mínimo 3 itens
- Um link para **outra página do seu projeto** (`href="./outra-pagina.html"`)
- Um link de **âncora** dentro da própria página (`href="#id"`)
- Um link **externo** com `target="_blank"` e `rel="noopener noreferrer"`
- Código validado no W3C sem erros

---

## Critérios de Avaliação

| Critério | O que será observado |
|---|---|
| **Validade** | Sem erros no W3C Validator |
| **Estrutura** | DOCTYPE, lang, charset, viewport, title presentes |
| **Semântica** | Hierarquia de headings correta, `alt` descritivo |
| **Links** | Os três tipos funcionando corretamente |
| **Legibilidade** | Indentação consistente, código organizado |
| **Criatividade** | A página tem identidade — não é cópia do exemplo |

---

<Callout type="tip" title="Dica — comece pelo conteúdo, não pelo código">
  Antes de abrir o VS Code, pense: *sobre o que é minha página? Qual o título? Quais são as seções?* Escreva isso no papel ou num bloco de notas. Quando você sabe o que quer dizer, o HTML vem mais fácil.
</Callout>
