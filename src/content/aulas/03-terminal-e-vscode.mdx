## Por Que o Terminal?

Antes de escrever a primeira linha de HTML, você precisa saber **onde** está trabalhando. O terminal é a forma mais direta de criar pastas, navegar entre elas e abrir o editor — sem depender de cliques e janelas gráficas.

Profissionais de desenvolvimento vivem no terminal. Aprender o básico agora vai eliminar muita confusão futura.

<Callout type="info" title="Terminal no Windows, Mac e Linux">
  No **Windows**, use o **PowerShell** ou o **Git Bash** (instalado junto com o Git). No **Mac**, use o **Terminal** nativo. No **Linux**, qualquer terminal. Os comandos desta aula funcionam em todos eles.
</Callout>

## Navegando pelo Sistema de Arquivos

O terminal sempre está "dentro" de uma pasta — chamada de **diretório atual**. Os comandos abaixo são os mais usados:

| Comando | O que faz | Exemplo |
|---|---|---|
| `pwd` | Mostra em qual pasta você está | `pwd` |
| `ls` | Lista o conteúdo da pasta atual | `ls` |
| `cd nome` | Entra em uma pasta | `cd Documentos` |
| `cd ..` | Volta uma pasta acima | `cd ..` |
| `cd ~` | Vai direto para a pasta home | `cd ~` |
| `mkdir nome` | Cria uma nova pasta | `mkdir meu-projeto` |
| `touch arquivo` | Cria um arquivo vazio | `touch index.html` |
| `clear` | Limpa a tela do terminal | `clear` |

<Callout type="tip" title="Tab para autocompletar">
  Você não precisa digitar o nome inteiro. Digite as primeiras letras e pressione **Tab** — o terminal completa automaticamente. Se houver mais de uma opção, pressione Tab duas vezes para listar todas.
</Callout>

## Criando o Projeto da Página Pessoal

Vamos criar a estrutura de pastas do projeto que vamos desenvolver ao longo das aulas. Em sala, fazemos isso juntos no terminal:

<Terminal>
  <span class="term-comment"># 1. Vai para a pasta de documentos (ou onde preferir)</span>
  <span class="term-prompt">$</span> cd ~/Documentos
  <span class="term-comment"># 2. Cria a pasta do projeto</span>
  <span class="term-prompt">$</span> mkdir minha-pagina
  <span class="term-comment"># 3. Entra na pasta criada</span>
  <span class="term-prompt">$</span> cd minha-pagina
  <span class="term-comment"># 4. Cria o arquivo HTML principal</span>
  <span class="term-prompt">$</span> touch index.html
  <span class="term-comment"># 5. Confirma o que foi criado</span>
  <span class="term-prompt">$</span> ls
  <span class="term-out">index.html</span>
</Terminal>

<Callout type="warn" title="Nomes de pasta — sem espaços, sem acento">
  Use sempre letras minúsculas, hífens no lugar de espaços, sem acentos. `minha-pagina` é válido. `Minha Página` vai causar problemas no terminal e em URLs.
</Callout>

## Abrindo o VS Code pelo Terminal

Com o VS Code instalado e configurado corretamente, um único comando abre o editor já na pasta certa:

<Terminal>
  <span class="term-comment"># Abre o VS Code na pasta atual</span>
  <span class="term-prompt">$</span> code .
</Terminal>

O ponto (`.`) significa "pasta atual". O VS Code abre mostrando exatamente os arquivos do seu projeto na barra lateral.

<Callout type="info" title='Se "code ." não funcionar'>
  No VS Code, abra a paleta de comandos com `Ctrl+Shift+P` (ou `Cmd+Shift+P` no Mac), pesquise por **"Shell Command: Install 'code' command in PATH"** e execute. Depois feche e reabra o terminal.
</Callout>

## Atalhos Essenciais do VS Code

Aprender os atalhos certos elimina metade da fricção do trabalho diário:

| Atalho | O que faz |
|---|---|
| `Ctrl + S` | Salva o arquivo atual |
| `Ctrl + Z` | Desfaz a última ação |
| `Ctrl + Shift + Z` | Refaz |
| `Ctrl + /` | Comenta / descomenta a linha selecionada |
| `Ctrl + D` | Seleciona a próxima ocorrência da palavra atual |
| `Alt + ↑ / ↓` | Move a linha selecionada para cima ou para baixo |
| `Ctrl + P` | Abre um arquivo pelo nome (busca rápida) |
| `Ctrl + Shift + P` | Paleta de comandos (tudo que o VS Code faz) |
| `Ctrl + \`` | Abre o terminal integrado do VS Code |
| `Ctrl + B` | Mostra / esconde a barra lateral |

<Callout type="tip" title="O terminal integrado">
  Você não precisa alternar entre janelas. O VS Code tem um terminal embutido — pressione `Ctrl+\`` e ele abre direto na pasta do projeto aberto. É o mesmo terminal, com os mesmos comandos.
</Callout>

## Extensões Recomendadas para HTML

Antes de começar a escrever HTML, instale estas extensões no VS Code:

| Extensão | Por que instalar |
|---|---|
| **Prettier** | Formata o código automaticamente ao salvar |
| **Live Server** | Abre o HTML no navegador e atualiza em tempo real |
| **Auto Rename Tag** | Quando você renomeia uma tag de abertura, a de fechamento é renomeada junto |
| **HTML CSS Support** | Autocomplete de classes CSS dentro do HTML |

Para instalar: `Ctrl+Shift+X` abre a aba de extensões. Pesquise o nome e clique em Install.

---

## Live Server — Vendo as mudanças em tempo real

Com o Live Server instalado:

1. Abra seu `index.html` no VS Code
2. Clique com o botão direito no arquivo
3. Selecione **"Open with Live Server"**
4. O navegador abre automaticamente em `localhost:5500`
5. Cada vez que você salvar (`Ctrl+S`), o navegador atualiza sozinho

<Callout type="tip" title="Sem precisar dar F5 toda hora">
  O Live Server elimina o loop chato de "edita → salva → vai no navegador → dá F5". Você edita, salva, e a página atualiza sozinha. Use isso do primeiro dia.
</Callout>

## Exercícios

<ExCard num={1} title="Crie a estrutura do projeto">

No terminal, execute a sequência:

1. Navegue até onde quer criar o projeto (`cd ~/Documentos` ou similar)
2. Crie uma pasta chamada `minha-pagina`
3. Entre nela com `cd minha-pagina`
4. Crie o arquivo `index.html` com `touch index.html`
5. Abra o VS Code com `code .`
6. Confirme que o `index.html` aparece na barra lateral

</ExCard>

<ExCard num={2} title="Explore os atalhos">

Com o VS Code aberto:

1. Abra o terminal integrado com `Ctrl+\``
2. Confirme em qual pasta você está com `pwd`
3. Crie uma pasta `assets` com `mkdir assets`
4. Volte para o editor e confirme que ela apareceu na barra lateral
5. Feche a barra lateral com `Ctrl+B` e reabra

</ExCard>

<ExCard num={3} title="Instale as extensões">

1. Abra a aba de extensões com `Ctrl+Shift+X`
2. Instale: **Prettier**, **Live Server**, **Auto Rename Tag**
3. Crie um arquivo `teste.html` com conteúdo qualquer
4. Clique com botão direito → **Open with Live Server**
5. Faça uma edição e salve — observe o navegador atualizar

</ExCard>
