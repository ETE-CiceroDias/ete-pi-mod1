01 · O que é Git

Controle de versão

Imagina que você está fazendo um trabalho escolar no Word. Você salva o arquivo, faz mais alterações, salva de novo. Aí você percebe que errou — mas não tem como voltar pra versão de ontem. A maioria das pessoas resolve isso assim: trabalho_final.docx, trabalho_final_v2.docx, trabalho_final_agora_vai.docx.

Com código, esse problema é ainda maior. Você pode ter dezenas de arquivos, alterações que quebram funcionalidades que estavam funcionando, e várias pessoas mexendo no mesmo projeto ao mesmo tempo. É aí que entra o Git.

Sem Git
index.html index_v2.html index_backup.html index_final_v3_agora.html
Caos. Qual é o arquivo certo? Quem mexeu o quê?
Com Git
feat: adiciona navbar
fix: corrige link quebrado
style: ajusta cores HEAD
Histórico organizado. Cada mudança registrada com motivo.
Git vs GitHub — não é a mesma coisa
Git
Uma ferramenta que fica no seu computador. Ele registra o histórico de alterações dos seus arquivos localmente. Funciona mesmo sem internet.
instalado na sua máquina
GitHub
Uma plataforma na nuvem onde você hospeda seu repositório Git. Permite colaboração, backup remoto e portfólio para o mercado.
site na internet
Analogia: Git é como o "histórico" do seu navegador — só que para código. GitHub é como o Google Drive — só que para repositórios Git.
02 · Mercado de trabalho

Por que todo dev usa

Git não é uma ferramenta opcional. Qualquer vaga de desenvolvimento — frontend, backend, mobile ou dados — exige que você saiba usar Git. Não é diferencial, é requisito básico.

Toda empresa usa
De startups a grandes empresas como Nubank, iFood e Mercado Livre — todas usam Git no dia a dia. Sem Git, você não passa pela entrevista técnica.
Trabalho em equipe
Em um time, várias pessoas mexem no mesmo código ao mesmo tempo. O Git é o que evita que o trabalho de uma pessoa sobrescreva o da outra.
Segurança do código
Com Git, nada se perde. Se um bug surgir em produção, você identifica qual commit causou e reverte para a versão anterior com um comando.
Portfólio no GitHub
O GitHub é o seu currículo como dev. Recrutadores olham seu perfil para ver o que você construiu, como você escreve commits e com que frequência você contribui.
Dado real: Git aparece em mais de 90% das vagas de desenvolvimento no Brasil. Dominar Git é uma das habilidades com melhor custo-benefício para quem está começando na área.

04 · Preparação

Instalando o Git

Antes de qualquer coisa, o Git precisa estar instalado no seu computador. Siga o passo a passo do seu sistema operacional.

Windows
  1. Acesse git-scm.com/install e clique em Download for Windows
  2. Execute o instalador e clique em Next em todas as telas — as opções padrão já estão corretas
  3. Na tela "Adjusting your PATH environment", escolha "Git from the command line and also from 3rd-party software"
  4. Conclua a instalação e abra o Git Bash que foi instalado junto
  5. Confirme rodando: git --version
macOS
  1. Abra o Terminal
  2. Rode: xcode-select --install
  3. Uma janela vai aparecer — clique em Instalar
  4. Confirme com: git --version
Linux (Ubuntu/Debian)
  1. Abra o terminal
  2. Rode: sudo apt update && sudo apt install git
  3. Confirme com: git --version
Git · Instalador oficial
Disponível para Windows, Mac e Linux em git-scm.com.
git-scm.com/install
GitHub Desktop opcional
Interface visual para quem está começando. Facilita ver o histórico de commits sem decorar todos os comandos.
desktop.github.com
Depois de instalar, rode git --version. Se aparecer algo como git version 2.x.x, está funcionando!
Configure seu nome e e-mail — o Git vai usar esses dados em todos os seus commits:
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

06 · Referência

Comandos essenciais

Cola no seu caderno ou salva no celular. Esses são os comandos que você vai usar todo dia.

Comando
O que faz
git init
Inicia um repositório Git na pasta atual
git status
Mostra o estado atual — o que mudou, o que está preparado
git add .
Prepara todos os arquivos modificados para o commit
git add arquivo.html
Prepara só um arquivo específico
git commit -m "mensagem"
Salva um snapshot do projeto com uma descrição
git log --oneline
Lista o histórico de commits de forma resumida
git diff
Mostra exatamente o que mudou desde o último commit
Dica profissional: Sempre escreva a mensagem do commit no imperativo e em português ou inglês consistente. Ex: adiciona página de contato ou add contact page.
